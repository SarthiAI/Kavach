# Contributing

Kavach does not accept pull requests.

If you have found a bug or want to request a feature, please open an issue:
https://github.com/SarthiAI/Kavach/issues

For security reports, please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Why no PRs?

Kavach is developed under a closed contribution model. The codebase is licensed under the [Elastic License 2.0](LICENSE), and all copyright is held by the project maintainers. Keeping contributions closed lets us iterate quickly, ship security fixes without coordination overhead, and keep the licensing story simple. And after the LiteLLM fiasco, this is the best way to keep the code secure, even more important for something like Kavach.

Issues, bug reports, and feature requests are very welcome. Code contributions are not.
